# dsh-neutered REPL Profile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Executor for this plan is dsh-neutered itself.** Every file below is written by
> `neutered/bin/dsh-neutered` running headless against the local model, from prompts
> Claude generates out of the code blocks in this document. Claude never edits product
> files. New files are born as a scaffold prompt (imports and exported stubs, under 40
> lines) and then grown by exact OLD→NEW prompts of at most 6 edits each; a prompt that
> has produced nothing after 15 minutes is killed, split in half and retried.

**Goal:** Add a `repl` profile so `dsh-neutered` with no task opens a multi-turn terminal session on one Agent, with live tool lines, Esc to cancel, queued prompts, y/Esc approvals and `--resume`.

**Architecture:** A new bundle `packages/bundle/repl` forks the headless runner's Agent setup and replaces its one-shot `followup`/`whenIdle` with a loop fed by a pure keyboard state machine (`input.ts`) and a pure event renderer (`render.ts`). The wrapper picks the profile from "task text present / stdin is a TTY / stdin is a pipe". Gates and the wrapper test grow one case each.

**Tech Stack:** TypeScript (ESM, `.ts` imports), cordis plugins, commander, `node:readline` keypress events, vitest, bash, `/usr/bin/expect` for the pty gate.

**Spec:** `neutered/docs/2026-09-05-repl-design.md`

## Global Constraints

- Branch `worktree-repl` in the worktree `dsh-neutered/.claude/worktrees/repl`, based on `neutered` tip `64715244cd` (step 8 merged). Never push.
- Endpoint stays `http://127.0.0.1:1234/v1`; no new network primitive anywhere (static gate must report 0 destination and 0 primitive hits; `node:readline` and `node:tty` are not primitives).
- No slash commands, no `-p`, no web UI, no session picker, no `$EDITOR`.
- Exit codes: REPL exits 0 on Ctrl-C twice, Ctrl-D, stdin EOF; 1 on a runner failure; startup errors exit 2 through commander.
- Ctrl-C exit window: 1500 ms. Esc cancels with `agent.cancel({ kind: 'user' }, { keepInbox: true })`. Prompts during a turn go to `agent.followup`, never `agent.steer`.
- Approval answers are `'allowed-once'` for `y` and `'rejected'` for Esc; no answerer when stdin is not a TTY.
- `DSH_REPL_REASONING=0` hides provider reasoning; default shows it on stderr.
- Every prompt to dsh runs from the worktree root as cwd, with `DSH_HOME` set to a clean directory and `NODE_OPTIONS="--require=$HOME/.dsh/preload/slow-prefill.cjs"`, using the main checkout's built CLI: `/Users/m/Documents/dsh_neutered/dsh-neutered/neutered/bin/dsh-neutered --dsh "node /Users/m/Documents/dsh_neutered/dsh-neutered/apps/cli/lib/bin.js" -- "<prompt>"`.
- Commit after every task with `git add <files>` and a `neutered: step 9 (part N) — <what>` message.

```markdown
# @deepseek-ai/dsh-repl

## Summary

`dsh-repl` opens one agent session in the terminal and keeps it for the whole
process. Type a prompt and press Enter; the assistant text streams as it
arrives, every tool call and result takes one line, and provider reasoning
goes to stderr. Press Esc to cancel the running turn (queued prompts survive),
type during a turn to queue the next prompt, press Ctrl-C twice within 1.5 s
or Ctrl-D at an empty prompt to exit. Pasted text keeps its newlines
(bracketed paste); a trailing `\` continues a line by hand.

`dsh --profile repl` starts a fresh session and prints its id. `--resume`
continues the most recent persisted session, `--resume <id>` a given one,
`--sessions` lists the ten most recent and exits. When a tool asks for
approval, `y` allows it once and Esc rejects it. When stdin is not a
terminal, each line is one prompt, EOF exits, and approvals fail closed.

There are no slash commands. `DSH_REPL_REASONING=0` hides reasoning.

## Implementation

`src/startup.ts` parses the app arguments the launcher forwards and publishes
`replStartup`. `src/input.ts` is the keyboard state machine (pure), `src/render.ts`
turns session events into output lines (pure), `src/approval.ts` answers
`approval/request` for the REPL's agent, and `src/index.ts` creates or resumes
the Agent, wires the three together and owns the turn loop and exit.
```

```ts
/**
 * @deepseek-ai/dsh-repl/startup — the REPL app's command-line provider. It
 * parses the app arguments the launcher forwards (`dsh --profile repl
 * [--resume [id]] [--sessions]`) and publishes them as the `replStartup`
 * service the runner row reads.
 * @module @deepseek-ai/dsh-repl/startup
 */

import { Command } from 'commander'
import type { Context } from '@deepseek-ai/cordis'
import { parseCmdline } from '@deepseek-ai/dsh-cmdline'

/** Stable Cordis plugin name. */
export const name = 'repl-startup'

/** The launcher-provided argument vector. */
export const inject = ['cmdlineArgs']

/** Service name the bundle patch reads through `ctx.replStartup`. */
export const REPL_STARTUP_SERVICE = 'replStartup'

/** What the operator asked for on the command line. */
export interface ReplStartupValues {
  /** `true` resumes the most recent session, a string resumes that id, absent starts fresh. */
  resume?: string | true
  /** Print the ten most recent sessions and exit. */
  listSessions: boolean
}

function replCommand(): Command {
  return new Command()
    .name('dsh --profile repl')
    .description('Talk to the agent turn by turn in the terminal: Esc cancels a turn, Ctrl-C twice exits.')
    .helpOption('-h, --help', 'show this help')
    .option('--resume [id]', 'continue a persisted session: the most recent one, or the given id')
    .option('--sessions', 'list the ten most recent sessions and exit')
    .addHelpText('after', `
Examples:
  dsh --profile repl                 start a fresh session
  dsh --profile repl --resume        continue the most recent session
  dsh --profile repl --sessions      list sessions
`)
}

/**
 * Parse the app arguments and publish the startup values.
 * @param ctx - plugin context carrying the launcher's `cmdlineArgs` and `appExit`.
 */
export function apply(ctx: Context): void {
  const program = replCommand()
  program.action(() => {
    if (program.args.length > 0) {
      program.error(`error: unexpected argument ${JSON.stringify(program.args[0])}; the REPL takes no task text`)
    }
    const options = program.opts<{ resume?: string | true; sessions?: boolean }>()
    const values: ReplStartupValues = { listSessions: options.sessions === true }
    if (options.resume !== undefined) values.resume = options.resume
    ctx.provide(REPL_STARTUP_SERVICE, values)
  })
  parseCmdline(ctx, program)
}
```

```ts
import { describe, expect, it } from 'vitest'
import { TerminalInput } from '../src/input.ts'
import type { InputEvent, Key } from '../src/input.ts'

function machine(now: () => number = () => 0): { input: TerminalInput; echoed: () => string } {
  let echoed = ''
  const input = new TerminalInput({ write: text => { echoed += text } }, { now })
  return { input, echoed: () => echoed }
}

/** Feed printable text one keypress at a time, then the given special keys. */
function type(input: TerminalInput, text: string, ...keys: Key[]): (InputEvent | undefined)[] {
  const events: (InputEvent | undefined)[] = []
  for (const ch of text) events.push(input.keypress(ch, { sequence: ch, name: ch }))
  for (const key of keys) events.push(input.keypress(undefined, key))
  return events
}

const RETURN: Key = { name: 'return', sequence: '\r' }
const ESC: Key = { name: 'escape', sequence: '\x1b' }
const CTRL_C: Key = { name: 'c', ctrl: true, sequence: '\x03' }
const CTRL_D: Key = { name: 'd', ctrl: true, sequence: '\x04' }
const PASTE_START: Key = { name: 'paste-start', sequence: '\x1b[200~' }
const PASTE_END: Key = { name: 'paste-end', sequence: '\x1b[201~' }

describe('TerminalInput keypress mode', () => {
  it('submits the buffer on Enter and echoes what was typed', () => {
    const { input, echoed } = machine()
    const events = type(input, 'hi', RETURN)
    expect(events.at(-1)).toEqual({ type: 'submit', text: 'hi' })
    expect(echoed()).toBe('hi\n')
    expect(input.text).toBe('')
  })
  it('ignores Enter on a blank buffer', () => {
    const { input } = machine()
    expect(type(input, '  ', RETURN).at(-1)).toBeUndefined()
  })
  it('keeps newlines inside a bracketed paste and submits once at the end', () => {
    const { input } = machine()
    input.keypress(undefined, PASTE_START)
    type(input, 'one', RETURN)
    type(input, 'two')
    input.keypress(undefined, PASTE_END)
    expect(input.text).toBe('one\ntwo')
    expect(input.keypress(undefined, RETURN)).toEqual({ type: 'submit', text: 'one\ntwo' })
  })
  it('continues a line that ends with a backslash', () => {
    const { input } = machine()
    expect(type(input, 'a\\', RETURN).at(-1)).toBeUndefined()
    expect(type(input, 'b', RETURN).at(-1)).toEqual({ type: 'submit', text: 'a\nb' })
  })
  it('deletes with backspace', () => {
    const { input, echoed } = machine()
    type(input, 'ab', { name: 'backspace' })
    expect(input.text).toBe('a')
    expect(echoed()).toBe('ab\b \b')
  })
  it('emits cancel on Esc and clears the buffer', () => {
    const { input } = machine()
    expect(type(input, 'half', ESC).at(-1)).toEqual({ type: 'cancel' })
    expect(input.text).toBe('')
  })
  it('does not treat Esc inside a paste as cancel', () => {
    const { input } = machine()
    input.keypress(undefined, PASTE_START)
    expect(input.keypress(undefined, ESC)).toBeUndefined()
  })
  it('clears and hints on one Ctrl-C, exits on a second within the window', () => {
    let clock = 1000
    const { input, echoed } = machine(() => clock)
    expect(type(input, 'abc', CTRL_C).at(-1)).toBeUndefined()
    expect(input.text).toBe('')
    expect(echoed()).toContain('Ctrl-C again')
    clock += 1400
    expect(input.keypress(undefined, CTRL_C)).toEqual({ type: 'exit' })
  })
  it('does not exit when the second Ctrl-C is late', () => {
    let clock = 1000
    const { input } = machine(() => clock)
    input.keypress(undefined, CTRL_C)
    clock += 1600
    expect(input.keypress(undefined, CTRL_C)).toBeUndefined()
  })
  it('exits on Ctrl-D only when the buffer is empty', () => {
    const { input } = machine()
    expect(type(input, 'x', CTRL_D).at(-1)).toBeUndefined()
    input.keypress(undefined, ESC)
    expect(input.keypress(undefined, CTRL_D)).toEqual({ type: 'exit' })
  })
  it('maps y and Esc in approval mode and ignores other keys', () => {
    const { input } = machine()
    input.setMode('approval')
    expect(input.keypress('n', { name: 'n', sequence: 'n' })).toBeUndefined()
    expect(input.keypress('y', { name: 'y', sequence: 'y' })).toEqual({ type: 'approve' })
    expect(input.keypress(undefined, ESC)).toEqual({ type: 'reject' })
    expect(input.keypress(undefined, CTRL_C)).toEqual({ type: 'reject' })
    expect(input.text).toBe('')
  })
})

describe('TerminalInput line mode', () => {
  it('submits each non-blank line', () => {
    const { input } = machine()
    expect(input.line('hello')).toEqual({ type: 'submit', text: 'hello' })
    expect(input.line('   ')).toBeUndefined()
  })
  it('ignores lines while an approval is pending', () => {
    const { input } = machine()
    input.setMode('approval')
    expect(input.line('y')).toBeUndefined()
  })
})
```

```ts
/**
 * The REPL's keyboard state machine. It owns the line buffer, bracketed
 * paste, the Esc / Ctrl-C / Ctrl-D rules and the approval prompt. It is pure:
 * the runner feeds decoded keypresses (or whole lines when stdin is a pipe)
 * and acts on the events it returns; echo goes through the injected writer.
 * @module
 */

/** One decoded keypress as `readline.emitKeypressEvents` reports it. */
export interface Key {
  name?: string
  ctrl?: boolean
  meta?: boolean
  shift?: boolean
  sequence?: string
}

/** What the runner must do next. */
export type InputEvent =
  | { type: 'submit'; text: string }
  | { type: 'cancel' }
  | { type: 'exit' }
  | { type: 'approve' }
  | { type: 'reject' }

/** `prompt` edits a line; `approval` waits for y or Esc. */
export type InputMode = 'prompt' | 'approval'

export interface InputOptions {
  /** Milliseconds within which a second Ctrl-C exits (default 1500). */
  exitWindowMs?: number
  /** Clock for the Ctrl-C window; tests inject a fake. */
  now?: () => number

/** Terminal echo the machine wants written; the runner forwards it to stdout. */
export interface Echo {
  write(text: string): void
}

const EXIT_HINT = '\n(press Ctrl-C again to exit)\n'

export class TerminalInput {
  private buffer = ''
  private pasting = false
  private mode: InputMode = 'prompt'
  private lastInterrupt: number | undefined
  private readonly exitWindowMs: number
  private readonly now: () => number

  constructor(private readonly echo: Echo, options: InputOptions = {}) {
    this.exitWindowMs = options.exitWindowMs ?? 1500
    this.now = options.now ?? Date.now
  }

  /** The line being edited. */
  get text(): string {
    return this.buffer
  }

  setMode(mode: InputMode): void {
    this.mode = mode
  }

  /** Pipe mode: one complete line is one prompt; blank lines and approval-time lines are ignored. */
  line(text: string): InputEvent | undefined {
    if (this.mode === 'approval') return undefined
    if (text.trim() === '') return undefined
    return { type: 'submit', text }
  }

  /** TTY mode: one decoded keypress. */
  keypress(str: string | undefined, key: Key): InputEvent | undefined {
    if (key.name === 'paste-start') {
      this.pasting = true
      return undefined
    }
    if (key.name === 'paste-end') {
      this.pasting = false
      return undefined
    }
    if (key.ctrl === true && key.name === 'c') return this.interrupt()
    if (this.mode === 'approval') return this.approvalKey(key)
    if (key.ctrl === true && key.name === 'd') {
      return this.buffer === '' ? { type: 'exit' } : undefined
    }
    if (key.name === 'escape' && !this.pasting) {
      this.clear()
      return { type: 'cancel' }
    }
    if (key.name === 'return' || key.name === 'enter') return this.newline()
    if (key.name === 'backspace') {
      if (this.buffer !== '') {
        this.buffer = this.buffer.slice(0, -1)
        this.echo.write('\b \b')
      }
      return undefined
    }
    if (str !== undefined && str !== '' && key.ctrl !== true && key.meta !== true) {
      this.buffer += str
      this.echo.write(str)
    }
    return undefined
  }

  private newline(): InputEvent | undefined {
    if (this.pasting) {
      this.buffer += '\n'
      this.echo.write('\n')
      return undefined
    }
    if (this.buffer.endsWith('\\')) {
      this.buffer = `${this.buffer.slice(0, -1)}\n`
      this.echo.write('\n')
      return undefined
    }
    this.echo.write('\n')
    const text = this.buffer
    this.buffer = ''
    if (text.trim() === '') return undefined
    return { type: 'submit', text }
  }

  private interrupt(): InputEvent | undefined {
    const at = this.now()
    if (this.mode === 'approval') {
      this.lastInterrupt = at
      return { type: 'reject' }
    }
    if (this.lastInterrupt !== undefined && at - this.lastInterrupt <= this.exitWindowMs) {
      return { type: 'exit' }
    }
    this.lastInterrupt = at
    this.clear()
    this.echo.write(EXIT_HINT)
    return undefined
  }

  private approvalKey(key: Key): InputEvent | undefined {
    if (key.name === 'escape') return { type: 'reject' }
    if (key.sequence === 'y' || key.name === 'y') return { type: 'approve' }
    return undefined
  }

  private clear(): void {
    this.buffer = ''
    this.pasting = false
  }
}
```

```ts
/**
 * Session events to terminal lines for the REPL: assistant text streams to
 * stdout as it arrives, each tool call and each result takes one line, and
 * provider reasoning goes to stderr when enabled. Pure: the runner writes.
 * @module
 */

import type { SessionEvent } from '@deepseek-ai/dsh-session'

export interface RenderOptions {
  /** Forward provider reasoning to stderr. */
  reasoning: boolean
}

/** Which output lines are open, so the next line can close them first. */
export interface RenderState {
  /** Assistant text is open on stdout and its last character was not a newline. */
  textOpen: boolean
  /** Reasoning is open on stderr and its last character was not a newline. */
  reasoningOpen: boolean
}

export interface Rendered {
  out?: string
  err?: string
}

export function initialRenderState(): RenderState {
  return { textOpen: false, reasoningOpen: false }
}

const SUMMARY_WIDTH = 80

/** The first line of `text`, clipped to the summary width. */
export function clip(text: string): string {
  const line = text.split('\n', 1)[0] ?? ''
  return line.length > SUMMARY_WIDTH ? `${line.slice(0, SUMMARY_WIDTH - 1)}…` : line
}

/** The first non-blank string argument of a tool call, or the raw text when there is none. */
export function summarizeArguments(raw: string): string {
  try {
    const parsed: unknown = JSON.parse(raw)
    if (parsed !== null && typeof parsed === 'object') {
      for (const value of Object.values(parsed as Record<string, unknown>)) {
        if (typeof value === 'string' && value.trim() !== '') return clip(value.trim())
      }
    }
  } catch {
    // Not JSON: fall through to the raw text.
  }
  return clip(raw.trim())
}

function closeText(state: RenderState): string {
  if (!state.textOpen) return ''
  state.textOpen = false
  return '\n'
}

function closeReasoning(state: RenderState): string {
  if (!state.reasoningOpen) return ''
  state.reasoningOpen = false
  return '\n'
}

function merge(out: string, err: string): Rendered {
  const rendered: Rendered = {}
  if (out !== '') rendered.out = out
  if (err !== '') rendered.err = err
  return rendered
}

/** Render one session event of the REPL's own agent. */
export function renderEvent(event: SessionEvent, state: RenderState, options: RenderOptions): Rendered {
  switch (event.type) {
    case 'assistant/chunk': {
      const chunk = event.data.chunk
      if (chunk.type === 'text-delta') {
        if (chunk.text === '') return {}
        const err = closeReasoning(state)
        state.textOpen = !chunk.text.endsWith('\n')
        return merge(chunk.text, err)
      }
      if (chunk.type === 'reasoning-delta') {
        if (!options.reasoning || chunk.text === '') return {}
        const prefix = state.reasoningOpen ? '' : 'dsh: reasoning:\n'
        state.reasoningOpen = !chunk.text.endsWith('\n')
        return merge('', prefix + chunk.text)
      }
      return {}
    }
    case 'tool/call': {
      const out = closeText(state)
      const err = closeReasoning(state)
      return merge(`${out}> ${event.data.name}: ${summarizeArguments(event.data.arguments)}\n`, err)
    }
    case 'tool/result': {
      const block = event.data.message.content[0]
      const text = block.content.flatMap(part => part.type === 'text' ? [part.text] : []).join('\n')
      const lines = text === '' ? 0 : text.split('\n').length
      const status = event.data.error !== undefined
        ? `error ${event.data.error.code}`
        : block.isError === true ? 'error' : 'ok'
      const summary = clip(text.trim())
      const suffix = lines > 1 ? ` (${String(lines)} lines)` : ''
      return merge(`< ${status}${summary === '' ? '' : `: ${summary}`}${suffix}\n`, '')
    }
    case 'turn/end': {
      const out = closeText(state)
      let err = closeReasoning(state)
      const reason = event.data.reason
      if (reason.kind === 'error') err += `dsh: ${reason.error.code}: ${reason.error.message}\n`
      else if (reason.kind === 'aborted') err += 'dsh: turn cancelled\n'
      return merge(out, err)
    }
    default:
      return {}
  }
}
```

```ts
/**
 * The REPL's approval answerer: when the agent asks permission for a tool
 * action, print the request and take the operator's answer, y or Esc. The
 * runner installs it only when stdin is a terminal, so a piped session keeps
 * the fail-closed default of the approval service.
 * @module
 */

import type { Context } from '@deepseek-ai/cordis'
import type { Agent } from '@deepseek-ai/dsh-agent'
import type { ApprovalOutcome, ApprovalRequestEvent } from '@deepseek-ai/dsh-user-approval'

/** How the runner asks the operator one question and gets y (allow once) or Esc (reject). */
export interface ApprovalPrompter {
  ask(question: string, signal?: AbortSignal): Promise<'allowed-once' | 'rejected'>
}

/** One line naming the tool and, when given, why it asks. */
export function describeRequest(req: Pick<ApprovalRequestEvent, 'toolName' | 'reason'>): string {
  const reason = req.reason === undefined || req.reason.trim() === '' ? '' : `: ${req.reason.trim()}`
  return `approve ${req.toolName}${reason}? [y/Esc] `
}

/**
 * Register the answerer for exactly one agent; other agents' requests pass to
 * the next answerer and fail closed when there is none.
 * @param ctx - plugin context that sees the approval waterfall.
 * @param agent - the REPL's agent.
 * @param prompter - the terminal question.
 * @returns a disposer that unregisters the answerer.
 */
export function installApprovalAnswerer(ctx: Context, agent: Agent, prompter: ApprovalPrompter): () => void {
  const dispose = ctx.on('approval/request', (req: ApprovalRequestEvent, next: () => Promise<ApprovalOutcome>): Promise<ApprovalOutcome> => {
    if (req.agent !== agent) return next()
    return prompter.ask(describeRequest(req), req.signal)
  })
  return () => { dispose() }
}
```

```ts
/**
 * @deepseek-ai/dsh-repl — the interactive terminal driver. One Agent lives for
 * the whole process: every submitted prompt is a follow-up on it, Esc cancels
 * the running turn, prompts typed during a turn queue for the next one, and
 * Ctrl-C twice, Ctrl-D or stdin EOF flushes the Session and exits.
 *
 * @module @deepseek-ai/dsh-repl
 */

import { randomUUID } from 'node:crypto'
import { createInterface, emitKeypressEvents } from 'node:readline'
import type { Readable } from 'node:stream'
import type { Context } from '@deepseek-ai/cordis'
import z from '@deepseek-ai/schemastery'
import { brandString } from '@deepseek-ai/dsh-brand'
import { installModelSelection } from '@deepseek-ai/dsh-agent'
import type { Agent, ModelSelectionRef } from '@deepseek-ai/dsh-agent'
import type {} from '@deepseek-ai/dsh-agent-default-model'
import { createUserMessage } from '@deepseek-ai/dsh-llm'
import type { SessionHeader, SessionId } from '@deepseek-ai/dsh-session'
// Empty type imports carry the Context merges for sessionPersistence, the
// loader settlement await and the cmdline appExit host value.
import type {} from '@deepseek-ai/dsh-session-persistence'
import type {} from '@deepseek-ai/cordis-plugin-loader'
import type {} from '@deepseek-ai/dsh-cmdline'
import { installApprovalAnswerer } from './approval.ts'
import { TerminalInput } from './input.ts'
import type { InputEvent, Key } from './input.ts'
import { initialRenderState, renderEvent } from './render.ts'

/** Stable Cordis plugin name. */
export const name = 'repl-runner'

/** Core services required before the session can start. */
export const inject = ['agentDefaultModel', 'agents', 'sessions']

/** Plugin config: the startup values resolved from this app's provider service. */
export interface Config {
  /** `true` resumes the most recent persisted session, a string resumes that id, absent starts fresh. */
  resume?: string | true
  /** Print the ten most recent sessions and exit. */
  listSessions: boolean
}

export const Config: z<Config> = z.object({
  resume: z.union([z.string(), z.const(true)]),
  listSessions: z.boolean().default(false),
})

/** The stdin the runner reads; a terminal exposes raw mode. */
export type ReplStdin = Readable & {
  isTTY?: boolean
  setRawMode?(mode: boolean): unknown
}

/** Process-facing effects of the session: streams, environment, bounded exit request. */
interface ReplIo {
  stdin: ReplStdin
  stdout: { write(chunk: string): unknown }
  stderr: { write(chunk: string): unknown }
  env: NodeJS.ProcessEnv
  exit(code: number): void
}

/** The process streams the runner uses; tests substitute captures. */
export const internals: Omit<ReplIo, 'exit'> = {
  stdin: process.stdin,
  stdout: process.stdout,
  stderr: process.stderr,
  env: process.env,
}

const PROMPT = 'dsh> '
const PASTE_ON = '\x1b[?2004h'
const PASTE_OFF = '\x1b[?2004l'
const LISTING_LIMIT = 10

/** Persisted session headers, newest first. */
async function recentSessions(ctx: Context): Promise<SessionHeader[]> {
  const persistence = ctx.get('sessionPersistence')
  const headers = persistence === undefined ? [] : await persistence.list()
  return [...headers].sort((a, b) => b.createdAt - a.createdAt)
}

async function printSessions(ctx: Context, io: ReplIo): Promise<void> {
  const recent = (await recentSessions(ctx)).slice(0, LISTING_LIMIT)
  if (recent.length === 0) {
    io.stdout.write('no persisted sessions\n')
    return
  }
  for (const header of recent) {
    io.stdout.write(`${new Date(header.createdAt).toISOString()}  ${header.id}  ${header.cwd ?? ''}\n`)
  }
}

/** Report an unexpected driver failure and request a failing exit. */
function fail(io: ReplIo, error: unknown): void {
  io.stderr.write(`dsh: ${error instanceof Error ? error.message : String(error)}\n`)
  io.exit(1)
}

/**
 * Create or resume the Agent, then drive it from stdin until exit.
 * @param ctx - plugin context carrying the Agent registry, default model, Sessions and launcher IO.
 * @param config - validated startup values.
 * @param io - process-facing effects.
 */
async function run(ctx: Context, config: Config, io: ReplIo): Promise<void> {
  // Loader siblings mount concurrently. Await the complete application before
  // creating an Agent so its scoped tools and adapters are not half-composed.
  await ctx.get('loader')?.await()
  if (config.listSessions) {
    await printSessions(ctx, io)
    io.exit(0)
    return
  }
  const agents = ctx.get('agents')
  const defaultModel = ctx.get('agentDefaultModel')
  const sessions = ctx.get('sessions')
  // Early process shutdown can dispose the tree while settlement is pending.
  if (agents === undefined || defaultModel === undefined || sessions === undefined) return

  const selection = defaultModel.currentSelection()
  const agentOptions = { provider: selection.provider, model: selection.model }
  const setup = (agentCtx: Context): void => {
    const selected: ModelSelectionRef = { current: selection, assembled: undefined }
    installModelSelection(agentCtx, selected)
  }
  let agent: Agent
  if (config.resume === undefined) {
    ({ agent } = await agents.create({
      sessionId: brandString<SessionId>(`session-${randomUUID()}`),
      meta: { cwd: process.cwd() },
      agentOptions,
      setup,
    }))
    io.stdout.write(`session ${agent.session.id}\n`)
  } else {
    const id = config.resume === true
      ? (await recentSessions(ctx))[0]?.id
      : brandString<SessionId>(config.resume)
    if (id === undefined) throw new Error('no persisted session to resume')
    ({ agent } = await agents.resume({ resumeSessionId: id, agentOptions, setup }))
    io.stdout.write(`session ${agent.session.id} (resumed)\n`)
  }
  await agent.whenIdle()

  const tty = io.stdin.isTTY === true
  const state = initialRenderState()
  const reasoning = io.env.DSH_REPL_REASONING !== '0'
  const stopRender = ctx.on('session/event', (session, event) => {
    if (session !== agent.session) return
    const rendered = renderEvent(event, state, { reasoning })
    if (rendered.out !== undefined) io.stdout.write(rendered.out)
    if (rendered.err !== undefined) io.stderr.write(rendered.err)
  })

  const input = new TerminalInput({ write: (text) => { if (tty) io.stdout.write(text) } })
  let running = false
  let finished = false
  let teardown = (): void => {}
  let stopApproval = (): void => {}
  let pendingApproval: ((outcome: 'allowed-once' | 'rejected') => void) | undefined

  const prompt = (): void => {
    if (tty && !finished) io.stdout.write(PROMPT)
  }
  const isBusy = (): boolean => running || agent.status === 'running' || agent.inbox.hasPending
  const settle = async (): Promise<void> => {
    // Queued follow-ups start their own turns; wait until nothing is pending.
    while (isBusy()) {
      await agent.whenIdle()
      await new Promise<void>(resolve => setImmediate(resolve))
      if (agent.status !== 'running' && !agent.inbox.hasPending) break
    }
  }
  const finish = async (): Promise<void> => {
    if (finished) return
    finished = true
    teardown()
    stopApproval()
    stopRender()
    await sessions.flush(agent.session)
    io.exit(0)
  }
  const submit = (text: string): void => {
    agent.followup(createUserMessage({ content: [{ type: 'text', text }], source: { kind: 'user' } }))
    if (running) {
      io.stdout.write(`queued (${String(agent.inbox.nextTurn.length)})\n`)
      return
    }
    running = true
    void settle().then(() => {
      running = false
      prompt()
    })
  }
  const dispatch = (event: InputEvent | undefined): void => {
    if (event === undefined || finished) return
    switch (event.type) {
      case 'submit':
        submit(event.text)
        return
      case 'cancel':
        if (running) agent.cancel({ kind: 'user' }, { keepInbox: true })
        else prompt()
        return
      case 'exit':
        void finish().catch((error: unknown) => { fail(io, error) })
        return
      case 'approve':
        pendingApproval?.('allowed-once')
        return
      case 'reject':
        pendingApproval?.('rejected')
        return
    }
  }

  if (tty) {
    stopApproval = installApprovalAnswerer(ctx, agent, {
      ask: (question, signal) => new Promise((resolve) => {
        io.stdout.write(`\n${question}`)
        input.setMode('approval')
        const answer = (outcome: 'allowed-once' | 'rejected'): void => {
          signal?.removeEventListener('abort', onAbort)
          pendingApproval = undefined
          input.setMode('prompt')
          io.stdout.write('\n')
          resolve(outcome)
        }
        const onAbort = (): void => { answer('rejected') }
        signal?.addEventListener('abort', onAbort, { once: true })
        pendingApproval = answer
      }),
    })
    emitKeypressEvents(io.stdin)
    io.stdin.setRawMode?.(true)
    io.stdout.write(PASTE_ON)
    const onKeypress = (str: string | undefined, key: Key | undefined): void => {
      dispatch(input.keypress(str, key ?? {}))
    }
    io.stdin.on('keypress', onKeypress)
    io.stdin.resume()
    teardown = () => {
      io.stdin.off('keypress', onKeypress)
      io.stdout.write(PASTE_OFF)
      io.stdin.setRawMode?.(false)
      io.stdin.pause()
    }
  } else {
    const lines = createInterface({ input: io.stdin, crlfDelay: Infinity, terminal: false })
    lines.on('line', (line) => { dispatch(input.line(line)) })
    lines.on('close', () => {
      void settle().then(() => { dispatch({ type: 'exit' }) })
    })
    teardown = () => { lines.close() }
  }
  prompt()
}

/**
 * Mount the interactive driver.
 * @param ctx - plugin context carrying core services and the launcher-provided exit request.
 * @param config - validated startup values.
 */
export function apply(ctx: Context, config: Config): void {
  // Read through the global service store, not the property proxy: appExit is
  // an optional host value, never an injected dependency.
  const exit = ctx.get('appExit')
  if (exit === undefined) {
    throw new Error('repl-runner: the launcher must provide ctx.appExit before the tree mounts')
  }
  const io: ReplIo = { ...internals, exit }
  void run(ctx, config, io).catch((error: unknown) => { fail(io, error) })
}
```

- [ ] **Step 1: Write the expect driver**

```tcl
#!/usr/bin/expect -f
# Drive one dsh-neutered REPL session under a pty for the capture gate:
# wait for the prompt, send the task, wait for the marker, exit with Ctrl-C twice.
# Arguments: <wrapper> <dsh command> <task> <marker regex>
set timeout 900
lassign $argv wrapper dsh task marker
spawn $wrapper --dsh $dsh
expect {
  -re {dsh> } {}
  timeout { puts stderr "repl-session: no prompt within 900 s"; exit 3 }
  eof { puts stderr "repl-session: exited before the prompt"; exit 3 }
}
send -- "$task\r"
expect {
  -re $marker {}
  timeout { puts stderr "repl-session: no $marker within 900 s"; exit 4 }
  eof { puts stderr "repl-session: exited before answering"; exit 4 }
}
expect {
  -re {dsh> } {}
  timeout { puts stderr "repl-session: no prompt after the answer"; exit 5 }
  eof { puts stderr "repl-session: exited after answering"; exit 5 }
}
send -- "\003\003"
expect eof
lassign [wait] pid spawnid oserr rc
exit $rc
```

## As built (2026-09-05)

Every file was written by dsh-neutered from these code blocks (scaffold plus
marker-anchored append edits, then exact OLD→NEW fixes); each result was diffed
against the reference copy before the next prompt ran. Where the code above
differs from the committed tree, the tree is right:

- Usage errors exit 1, not 2: commander's `program.error` and its own "too many
  arguments" rejection both exit 1, as the headless parser's test already
  expected. The parser's dead argument check is gone and the test asserts
  commander's message.
- The approval package exports the request type as `ApprovalRequest`;
  `approval.ts` and its test import that name and let the listener parameter
  infer from the `approval/request` event.
- `throw new Error(...)` on one line before `({ agent } = ...)` parses as a call
  without semicolons; the throw sits in braces.
- The runner test's fake agent appends each follow-up to the real `Inbox` and
  claims it when the turn opens, as a live driver does, so `queued (1)` holds.
- The build gate belongs to Task 7, not Task 1: tsdown enumerates every
  workspace package and needs the `tsconfig.host.json` reference before the
  host type emission produces `lib/types` for the new bundle.
- The capture gate strips CR and trailing blanks from the pty transcript it
  quotes in its report, so the report passes the repository's whitespace hook.
- The escape sequences in this document are written as `\x1b` and `\x03`; an
  earlier revision carried the raw bytes, which the model cannot type.
- The runner's `settle` waits for the driver to go idle, not for an empty
  inbox: a cancelled turn leaves its queued prompts pending until the next
  prompt wakes the driver, and the old loop spun there without a prompt. It
  now prints `pending (n): the next prompt runs them first`.
- Expect scripts must use the multi-line `expect { ... }` form; on this
  machine's expect 5.45 the one-line form is read as a single glob pattern
  that never matches, which made an early live scenario look like input was
  ignored during a turn. Under `script(1)` and under the shipped multi-line
  driver, input during a turn queues as designed.
